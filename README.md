# Cyber-Bot Privacy Policy

## 1. Data We Collect
We collect limited data necessary to provide server management and moderation features. This includes:
- Discord User IDs and Username strings.
- Server (Guild) IDs and channel configurations.
- Log data for moderation actions (infractions, bans, mutes), which is retained indefinitely to support server accountability, staff review, and tracking of repeat-offending users.

## 2. How We Use Data
Data is used solely to operate the bot's features, such as processing text commands, executing auto-moderation filters, and displaying server analytics via the dashboard.

## 3. Data Sharing
We do not sell, rent, or share any user data with third parties.

## 4. Infrastructure and Processing
This bot is a custom instance powered by the Dyno framework. All backend data processing and storage adhere strictly to the global privacy and security standards managed by Dyno (https://dyno.gg/privacy).

## 5. Data Deletion
Users can request the removal of their data by contacting the bot administrator at cyberdroidx@gmail.com or by removing the bot from their server.
